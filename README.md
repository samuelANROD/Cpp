# C++: Meu Caderno de Estudos

Bem-vindo ao meu repositório de estudos de C++.

Aqui reúno tudo o que aprendo sobre C++: desde os fundamentos da linguagem até conceitos avançados, ferramentas e projetos práticos. A ideia é documentar minha evolução, armazenando exemplos, exercícios e projetos.

> **Em construção constante.** Este repositório crescerá junto com meus estudos.

---

## Objetivo

Construir uma base sólida em C++, explorando:

- Fundamentos da linguagem
- Gerenciamento de memória
- Programação Orientada a Objetos
- Standard Template Library (STL)
- Templates e recursos modernos do C++
- Estruturas de dados e algoritmos
- Projetos práticos

---

## Estrutura do repositório

```text
C++/
├── Hello_World/
│   └── main.cpp
└── ...
```

Cada diretório representa um tema estudado, contendo exemplos e exercícios em arquivos `.cpp`.
